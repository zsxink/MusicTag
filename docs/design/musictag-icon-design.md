# MusicTag 应用图标 · 设计规范

日期：2026-08-04
状态：最终版（已由用户逐项确认并采纳）

## 背景

MusicTag 是一款编辑音乐文件（flac / mp3 等）标签信息的应用，核心功能是编辑
封面、歌词、专辑等元数据。本设计为其设计应用图标。

## 核心创意

「音乐 + 标签」的双关：用**跳跃的音乐波形**表达「音乐」，用**吊牌（标签）**
表达「编辑标签」这一核心功能。整体传递「给音乐文件贴标签」的直白语义。

## 设计决策（用户逐项确认）


| 维度   | 选择                                                                     |
| ---- | ---------------------------------------------------------------------- |
| 主体图形 | **均衡器式跳跃波形**（音乐）+ **吊牌形标签**（标签）                                        |
| 视觉风格 | **扁平色块**——纯色几何造型，无渐变、无描边                                               |
| 容器   | **圆角方块（squircle）**                                                     |
| 配色方向 | **深色底 + 荧光强调**                                                         |
| 强调色  | **青绿 / 薄荷**                                                            |
| 背景调子 | **深墨青绿**（偏青的深色，带绿色调，与强调色同色系）                                           |
| 波形形态 | **高低起伏、顶缘圆头、多色交错**（均衡器风格，左 5 + 右 5 镜像立柱）                               |
| 波形配色 | **奶白为主，点缀亮蓝 / 暖杏 / 柔粉 / 荧光青绿**（其中一根青绿与吊牌同色呼应）                          |
| 标签形状 | **手绘有机吊牌形**（🏷️）——顶部圆肩、两侧微弧、底端一侧带圆角缺口 + 顶部小圆孔                          |
| 标签姿态 | **3D 透视**——绕 Y 轴向左旋转（rotateY −20°）、绕 Z 轴向屏幕内倾斜（rotateZ 8°），呈现向左偏转的立体透视 |
| 标签侧厚 | **伪 3D 侧边**——右侧缘露出一条更深青绿的侧暗面，暗示吊牌厚度                                    |
| 构图   | **波形从标签后方穿出**，前后遮挡、有层次                                                 |
| 颜色分工 | **标签 = 荧光青绿（主角）**，**波形 = 多色、以奶白为主**                                    |


## 视觉规格

- 容器：圆角方块（squircle），深墨青绿底 `#102B26`（偏青的深色，带绿色调）
- 波形：均衡器式高低起伏的立柱，顶缘圆头（rx 18），左 5 右 5 镜像排列，左右
延伸超出吊牌两侧；颜色序列（左→右）：
奶白 → 亮蓝 → 奶白 → 暖杏 → 奶白 ｜ 柔粉 → 暖杏 → 荧光青绿 → 亮蓝 → 奶白
- 吊牌：居中偏前，荧光青绿色 `#31E0A8`，顶部小圆孔清晰可见，位于波形之上
- 吊牌透视：`transform="rotateY(-20 512 480) rotateZ(8 512 480)"`
—— 绕 Y 轴向左偏转、绕 Z 轴向屏幕内微倾；侧缘暗面 `#1C8A68` 制造伪 3D 厚度
- 质感：纯平填色，无渐变、无描边、无高光

## 小尺寸可读性

16×16 下轮廓依旧清晰：青绿吊牌居中，多色波形左右延伸。波形立柱高度错落，  
缩小时仍保留「音乐 + 标签」的轮廓辨识度。ß
