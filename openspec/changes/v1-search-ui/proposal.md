## Why

`v1-search-backend` 已提供 `search_song`/`fetch_lyric`/`download_cover` command。本变更落地前端搜索联动：选中即搜（仅一次、只补缺失）、候选区展示、点选写入、离线降级、搜索中/空态、候选生命周期切歌即弃、手动搜索按钮。这是 V1 的最后一个功能变更，完成后即端到端验收。

## What Changes

- **选中即搜（仅一次）**：选中歌曲那一刻，仅对缺失的歌词/封面自动并发搜 3 家（`search_song`）；已有内容、删除内容后均不再自动触发。
- **只补缺失**：已有歌词（内嵌或 `.lrc`）不搜歌词；已有封面不搜封面；两者都有不搜索。
- **候选区**：歌词候选条列表（来源 badge + 歌名—作者）；封面候选缩略图网格（3×N，来源角标）。
- **点选写入**：点选歌词候选 → `fetch_lyric` 拉文本填入歌词区（badge 更新来源，仍可继续编辑）；点选封面候选 → `download_cover` 下载填入封面区预览；不自动覆盖已有内容。
- **取词失败自动换源（C2）**：点选候选取词 None → 自动换另一家源重试同一首歌（按歌名+作者），不自动降级到低分候选；全源失败显示空态。
- **离线降级（失败首响）**：本会话第一次自动搜索全源失败 → 标记会话离线，后续选中不再自动搜、候选区不出现，界面提示「离线：仅手动填写」，只留手动搜索按钮。
- **手动搜索按钮**：歌词区、封面区各一个「搜索歌词 / 搜索封面」虚线按钮，随时可主动发起。
- **候选生命周期**：候选 = 当前歌曲，切歌即清空（不保留）；未点选候选切歌丢弃，无弹窗。
- **搜索进度**：候选区显示「搜索中…」（转圈），后台异步不阻塞编辑。
- **封面候选失败静默**：封面下载失败/图片损坏/压缩失败 → 静默忽略该张候选（不报错、不标红）。

## Capabilities

### New Capabilities
- `search-ui`: 选中即搜（仅一次/只补缺失）+ 候选区点选写入 + 离线降级 + 搜索中/空态 + 手动按钮 + 候选生命周期

### Modified Capabilities
（无）

## Impact

- 纯前端：复用 `v1-search-backend` 的 command、`v1-lyrics-lrc` 的歌词区、`v1-cover-embed` 的封面区。
- 新增组件：LyricCandidate、CoverCandidate、搜索态/空态 UI。
- store 增加搜索状态：`searchState`/`searchResults`/`isOffline`/`candidates`。
