# Proposal: compact top-bar update indicator

GitHub Issue: #188

## Why

The current red update indicator occupies a 28px circle and visually competes with the app name. The approved prototype uses a small red dot instead.

## Change

Reduce the top-bar update indicator to a compact red dot while retaining its existing presence condition, click-to-restore behavior, tooltip, and accessible name. Bump the app to v0.2.1 for release.

## Scope

This is a presentation-only adjustment to the existing update indicator. It does not change update detection, prompting, persistence, or release behavior.
