# candidate-collapse Specification

## Purpose

候选区折叠语义调整：折叠偏好从「跨切歌保持」改为「切歌后默认展开」。

## MODIFIED Requirements

### Requirement: 切歌后折叠重置为默认展开

切歌（换到另一首歌）时折叠偏好 SHALL 重置为默认展开——用户收起候选区后切歌，新歌的候选区默认展开，不沿用上一首的折叠态。这是产品决策：折叠偏好**不**跨切歌保持（原「跨切歌保持」实测不好用——收起后切歌，新歌候选区保持折叠易让用户误以为搜索没出结果，改为切歌即重置）。

#### Scenario: 切歌后默认展开

- **WHEN** 用户收起候选区后切换到另一首歌（候选生命周期重置）
- **THEN** 新歌的候选区默认展开（折叠态重置，按钮文案「隐藏候选 ▲」）

#### Scenario: 换目录/只读后默认展开

- **WHEN** 用户收起候选区后换目录（或打开坏标签只读歌），再重新选歌
- **THEN** 候选区折叠状态重置为默认展开
