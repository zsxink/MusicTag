# Issue 123: 目录变动后自动刷新文件列表

GitHub Issue: `#123`

## Why

打开目录后新增音频文件，列表可能保持旧内容；手动刷新和重启后重新打开仍可能显示旧列表，只有切换到子目录才恢复。用户需要目录内容变化能自动反映在文件列表中。

## What Changes

- 监听当前打开目录及其子目录中的文件系统变动，并自动重新读取列表。
- 目录切换、监听失败或应用生命周期变化时，监听目标与列表状态保持一致。
- 手动刷新仍可主动重新读取当前目录。

## Impact

涉及目录列表读取与前端状态刷新流程、Tauri 后端文件系统事件能力，以及 PRD/技术设计文档。
