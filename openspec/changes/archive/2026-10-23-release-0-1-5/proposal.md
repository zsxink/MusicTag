# 发布 v0.1.5

## 背景

`v0.1.4` 发布后，项目新增了 macOS Homebrew tap 安装渠道（PR #169）、原生应用菜单与更新检查节流（PR #171，issue #170），并完成了发行前合规整改——许可自洽、酷狗 HTTPS、数据披露与第三方归属清单（PR #172，issue #166）。现需复核这些变更，整理发布说明并准备 `v0.1.5`。

GitHub Issue：#173

## 范围

- 复核 `v0.1.4` 之后的用户可见变更（PR #169、#171、#172），检查其实现与测试是否满足已批准规格。
- 汇总自 `v0.1.4` 起的用户可见变化，更新 README 发布说明和版本徽章。
- 将应用版本元数据统一更新至 `0.1.5`。
- 使用现有 tag-triggered release workflow 创建 `v0.1.5` draft Release，并核对 CI 构建结果。

## 非目标

- 不增加新的产品功能。
- 不扩展自动下载或安装更新能力。
- 不调整与发布无关的功能或开发流程。

## 验收

- Tauri、Cargo、npm 与 README 的版本均为 `0.1.5`。
- README 发布说明准确概括 Homebrew 安装渠道、原生应用菜单、更新检查节流与合规整改等自 `v0.1.4` 以来的用户可见变化。
- 对上述变更完成独立复核；确认的问题在规格内修复并复审，或记录无 blocker/major。
- OpenSpec 全量校验与 CI 对齐验证通过。
- 合并后 `v0.1.5` tag-triggered workflow 成功，draft Release 与构建产物可核对。
