## Why

当前 README「项目简介」「核心特性」两节是**内部约束口吻**——混入「无批量（批量是 V2）、无在线曲库、无账号」「目标播放器：用户自研播放器 + Slat Player」等对外的非功能约束措辞，且文案有 AI 味。README 是仓库门面，应站在**产品视角**介绍「是什么、能做什么」，简约、准确、有画面感。

## What Changes

- **README 产品文案 v2**：以产品视角替换「项目简介」「核心特性」两节，只讲功能与价值。
- **删除非功能约束措辞**：移除「目标播放器 / 无批量 / 无在线曲库 / 无账号」句。
- **功能枚举**：支持格式 FLAC/MP3、编辑音乐标签（歌名/作者/专辑/专辑作者/音轨号/年份/流派）、编辑封面（点选或拖拽嵌入）、编辑歌词（内嵌 + 导出 .lrc）、自动搜索（选中即搜缺失歌词/封面，多源并发，候选手动点选写入）。
- **保留**：技术栈、常用命令、文档入口、协作流程四节（仓库文档属性，非产品文案）。

## Capabilities

### New Capabilities
- `readme-product-copy`: README 以产品视角介绍 MusicTag——定位（为本地音乐文件补全元数据）+ 五条功能能力（支持格式/编辑标签/编辑封面/编辑歌词/自动搜索）。非功能约束措辞不再出现在门面文案。

### Modified Capabilities
- `readme-product-copy`: 既有 README「项目简介」「核心特性」两节被产品文案 v2 替换。
