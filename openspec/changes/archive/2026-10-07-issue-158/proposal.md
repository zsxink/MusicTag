# 基于 GitHub Releases 检查应用更新

## 背景

用户需要知道 MusicTag 是否有新版本。应用应通过项目 GitHub Releases 检查可用更新，并清楚展示检查状态与结果。

## 范围

- 查询项目 GitHub Releases 的最新正式版，与当前应用版本比较；忽略草稿和预发布版本。
- 提供启动时检查和“帮助”菜单中的手动检查入口。
- 发现更新时显示不抢焦点的应用内提示，提供查看 Release 详情和稍后操作；稍后后对同一 Release 版本不重复提示。
- 在关于或设置界面显示当前版本和最近检查结果。
- 显示已是最新版本、检查中和检查失败等明确状态。

## 非目标

- 不自动打开浏览器、下载更新或安装更新。
- 不影响应用现有功能；检查失败、等待或展示提示均为非阻塞。

## 验收

- 正确比较版本并忽略草稿及预发布版本。
- 用户可手动检查并看到检查期间状态；启动时也会检查。
- 更新提示非阻塞且不抢焦点，提供查看详情与稍后操作；稍后后同一版本不重复提示，新版本仍可提示。
- 关于或设置展示当前版本与最近检查结果。
- Release 详情链接打开对应 GitHub Release 页面；没有自动下载或安装。
- 最新、失败等结果有明确反馈，检查不干扰现有功能。
