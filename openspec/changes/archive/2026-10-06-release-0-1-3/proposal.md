# 发布 v0.1.3

## 背景

`v0.1.2` 发布后，项目合入了封面导出、文件夹变化自动刷新、搜索源可用性与中英文语种适配，以及 pipe 基建修复。需要复核这些近期用户功能的实现，处理复核确认的问题，并发布 `v0.1.3`。

## 范围

- 复核 `v0.1.2` 之后的用户可见功能变更：PR #143、#151、#153；排查实现和测试中的缺陷并在本次授权范围内修复。
- 汇总可见功能更新 README 发布说明，并统一应用版本元数据至 `0.1.3`。
- 使用现有 tag-triggered release workflow 创建 `v0.1.3` draft Release，并核对构建结果。

## 非目标

- 不增加新的产品功能。
- 不修改 PR #155 等仅涉及开发流程的内容，除非复核发现其影响发布门禁的问题。

## 验收

- 版本元数据与发布徽章一致为 `0.1.3`。
- 近期用户功能复核有证据；发现的问题已修复并回归验证，或记录无问题。
- README 清楚列出自 `v0.1.2` 以来的用户可见变更。
- OpenSpec 全量校验与 CI 对齐验证通过，合并后 tag 构建成功。
