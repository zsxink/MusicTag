# 设计：README 推荐 Echo

## 范围与领域

- 领域：`docs`。
- 只在 README 增加一段简洁中文推荐说明，不改应用界面、运行时代码或其他产品行为。
- 说明 Echo 是本地优先的跨平台音乐播放器；明确 MusicTag 用于补全本地音乐元数据，Echo 用于管理和聆听本地曲库。不得声称两款软件自动同步或已实现软件内联动。
- 提供 Echo GitHub 仓库与发行版页面两个可访问链接；实际 URL 以实现时核对的 Echo 官方仓库为准。

## 规格追溯与验证矩阵

| 规格场景 | 设计依据 | 验收检查 |
|---|---|---|
| 用户从 README 了解 Echo | 以一段中文分别说明两款应用的定位，不加入超出推荐所需的功能承诺 | 文案明确 MusicTag 补全本地音乐元数据、Echo 管理和聆听本地曲库；不存在自动同步或联动承诺；仓库链接与发行版链接各自指向 Echo 对应页面 |

## 文件所有权与验证

- 实现唯一文件：仓库根目录 `README.md`；不改其他文件。
- 实现后逐项对照上表检查文案、链接目标和禁止性表述，并检查 Git diff 确认变更仅限 README。
- 运行 OpenSpec strict validate（当前 change；最终 Verify 按流水线要求运行全量校验）。这是纯文档变更，不需要业务测试；最终 Verify 仍按 workflow 执行其适用 CI 门禁。

## 风险与迁移

- 链接可能失效或指向非官方页面；实现时核对仓库与发行版目标。
- 无数据迁移、运行时兼容性或应用代码风险。
