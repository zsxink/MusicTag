## Requirements
### Requirement: README 推荐 Echo
README SHALL 以简洁中文介绍 Echo 是本地优先的跨平台音乐播放器，并说明它与 MusicTag 的互补定位。README SHALL 提供 Echo 仓库和发行版链接，且 SHALL NOT 暗示两款软件已有自动同步或联动能力。

#### Scenario: 用户从 README 了解 Echo
- **WHEN** 用户阅读 README 中的 Echo 推荐说明
- **THEN** 用户可以分别访问 Echo 仓库和发行版页面
- **AND** 用户能理解 MusicTag 用于补全本地音乐元数据、Echo 用于管理和聆听本地曲库
- **AND** 说明不声称两款软件自动同步或联动
